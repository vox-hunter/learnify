# Legacy Python/Streamlit Implementation

This directory contains the previous complex implementation of Learnify built with:
- Python/Streamlit backend
- MongoDB database integration  
- User authentication and session management
- Complex multi-page navigation
- Background job processing

The new simplified version (learnify.html) achieves the same core functionality with zero complexity.

## Running the Legacy Version

If you need to run the old version:

1. Install dependencies: `pip install -r requirements.txt`
2. Set up environment variables in `.env`
3. Run: `streamlit run Quiz_app/main.py`

The new simplified version is recommended for most use cases.
